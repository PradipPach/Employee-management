# Employee Management - Basic Version (React + Tailwind)

Run:
    npm install
    npm run dev

Folder structure:
    src/
      main.jsx                  starts the app
      App.jsx                   decides which page to show
      data.js                   companies, admins, employees
      components/
        CompanyList.jsx         page 1 - company list
        Login.jsx               page 2 - admin login
        Dashboard.jsx           page 3 - employees + salary
        LogoutPage.jsx          page 4 - after logout
